# تشغيل السيستم
1. أنشئ مشروع على supabase.com ثم شغّل `supabase/schema.sql` في SQL Editor.
2. Authentication > Providers > Email: اقفل "Confirm email".
3. انسخ `.env.example` إلى `.env` وحط الـ URL والـ anon key.
4. `npm install && npm run dev`
5. أول حساب تسجله يبقى أدمن. من صفحة "المستخدمين" تضيف ناس وتحدد صلاحياتهم.

# التقارير
جوه أي مشروع اضغط 📄 التقارير: اختر أسبوعي/شهري وأي تاريخ في الفترة، وصدّر PDF (من نافذة الطباعة اختر Save as PDF) أو Excel. الأسبوع من السبت للجمعة.
